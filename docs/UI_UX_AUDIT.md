# UI/UX Audit — portfolio_adil_usmani

**Auditor role:** senior UI/UX auditor (code-grounded review)
**Repo state:** `main` @ `6d020a4` — clean tree, in sync with `origin/main`
**Stack:** Next 14.2.35 · React 18 · Tailwind 3.4.17 · framer-motion · lucide-react

**Scope.** The default rendered screen is **UI v2.1** (`app/page.tsx:23` → `components/v2_1/PortfolioV2_1.tsx`) plus the shell it mounts (`RailV2`, `CommandPaletteV2`, `AssistantV2`, `PdfReaderV2`, `FooterV2`), the two real routes `/projects/[slug]` (`ProjectDetailView`) and `/skills` (`SkillsDetailView`), and the error surfaces (`app/error.tsx`, `app/global-error.tsx`). v1/v2 are reviewed only where they leak into the shared shell.

**Severity key:** `CRITICAL` = blocks comprehension, trust or access · `MODERATE` = real friction / WCAG AA miss · `MINOR` = polish.
Contrast ratios are computed from the literal token values in `app/globals.css` using the WCAG 2.x relative-luminance formula.

## 4. Accessibility

| # | Criterion | Severity | Finding | Fix |
|---|---|---|---|---|

| 4.2 | 1.4.3 contrast | **CRITICAL** | **Light theme text tokens fail AA.** `--color-signal: #ea580c` ≈ **3.56:1** on `#ffffff`/`#f8fafc`, used as body-size text: "Deep Dive →" at 10.5px (`HeroV2_1.tsx:429-431`), switcher labels, the systems CTA row (`SystemsV2_1.tsx:93`), `text-signal-2` on `bg-signal/10` (`ContactV2.tsx:120`). `--color-teal: #0d9488` ≈ **3.74:1** (`HeroV2_1.tsx:451` author line). `--color-lime: #16a34a` ≈ **3.0:1** (`ContactV2.tsx:194` "Message persisted."). | 4.3 | 4.1.3 status messages | **CRITICAL** | **Form errors and submission status are visual-only.** `ContactV2.tsx:259-275` renders error text with no `aria-invalid`, no `aria-describedby`, no `role="alert"`; the sent/error panels (lines 184-212) and the status word (line 102) are not live regions; the form sets `noValidate` (line 95), so native validation is off too. | 4.4 | 2.4.7 / 2.4.11 focus | MODERATE | `focus:outline-none` on contact inputs (`ContactV2.tsx:260`) and the project chat input (`ProjectDetailView.tsx:396`) leaves only a subtle border-hue change; v2/v2.1 components define no `focus-visible` styles at all (only `components/ui/*` do). | 4.6 | 2.3.3 motion | MODERATE | **No `prefers-reduced-motion` handling** in v2/v2.1 (the only repo reference is `v1/PortfolioV1.tsx`), yet the default view ships a boot typewriter, infinite `pulse-ring` dots (`ui.tsx:59-68`), a cursor-follow spotlight (`shell-context.tsx:68-82`), animated dash flows and a large animated `CyberBug` (`ProjectDetailView.tsx:95-97`). | Gate motion with framer-motion's `useReducedMotion()` and wrap the CSS animations in `@media (prefers-reduced-motion: reduce)`. |
